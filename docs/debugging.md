# 调试指南

先保存失败输入、随机种子、命令、预期与实际结果；减小事件序列，确认每步状态不变量，再修复根因。重复相同输入应得到相同结果。

- 报文：打印十六进制字段和字节偏移，分别检查长度、端序、首部校验及 UDP 伪首部。
- 重组：记录已读位置、连续位置、窗口右边界、乱序字节和 EOF；检查重叠去重与容量。
- 传输：记录每个段、ACK、窗口、计时器截止时间、RTO 和 FIN；在超时边界前、恰好到期和之后分别检查。
- 转发：记录最长前缀、TTL、下一跳、ARP 缓存键、队列与事件时间，独立检查 checksum。
- 路由：列出每轮邻居向量、成本、下一跳及超时；先同步收集再交付通告，避免顺序影响结论。
- 代理：记录请求行、消息边界、上游/客户端 socket 生命周期、缓存命中及线程退出；用本地受控服务复现分段读取和并发。

失败后重新运行最小用例及受影响的公开测试；性能问题用固定规模输入测量并记录环境、规模和耗时，不以打印或 sleep 作为同步机制。
