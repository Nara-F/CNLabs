# 实验 05：距离向量路由

## 概览（Overview）

实现一个离散轮次驱动的距离向量路由器，处理邻居通告、链路变化、过期和毒性逆转。建议投入 12–16 小时，包含实现、自主测试和报告。

## 学习目标（Learning Objectives）

完成后能够计算距离向量的候选成本，解释下一跳和平局选择；使用同步轮次追踪收敛和链路失效；构造过期、不可达和错误输入的测试；分析毒性逆转的作用及局限。

## 先修要求（Prerequisites）

使用 Python 3.11 或更新版本及标准库；掌握字典、不可变 dataclass、图的路径成本和单元测试。了解最短路径、链路状态变化及路由环路。

## 背景（Background）

节点只知道直连成本及邻居最近的完整距离向量。对于本节点 x、目的地 d 和邻居 v，候选成本为 `min(16, cost(x,v) + D_v(d))`；选择所有邻居中最小的有限值。到自身的距离固定为 0。16 表示不可达，等成本时选择名称字典序较小的下一跳。

向作为下一跳的邻居通告该目的地的距离 16，称为毒性逆转，可避免部分两节点相互依赖；三个或更多节点的环路仍可能出现。本教学协议使用完整向量和显式轮次，不包含 RIP 报文编码、UDP、触发更新、水平分割配置或真实网络时钟。

## 架构总览（Architecture Overview）

每个 `Router` 维护直连成本、各邻居最近的完整向量及其年龄。`routes()` 从当前状态计算路由；`advertise()` 针对接收邻居生成通告。模拟器在一轮先收集所有通告，再交付，最后按需要推进各节点计时，保证结果不依赖节点遍历顺序。

## 接口规范（Interface Specifications）

- `Router(name: str, timeout: int = 3)`：name 为非空字符串，timeout 为正整数且不是 bool；无效值抛 `ValueError`。初始本地路由为 `Route(0, None)`。
- `set_link(neighbor: str, cost: int | None) -> None`：邻居为非空且不同于本机的字符串；成本是 1–15 的整数，bool 无效；`None` 删除链路和该邻居的向量。非法输入抛 `ValueError`；删除不存在的有效邻居允许且无效果。
- `receive(neighbor: str, vector: dict[str, int]) -> None`：neighbor 必须是当前直连邻居；vector 是字典，键为非空字符串、值为 0–16 的整数，bool 无效。验证整个向量后复制并替换旧向量，年龄重置为 0；非法输入抛 `ValueError` 且状态不变。空字典有效。
- `routes() -> dict[str, Route]`：返回新的目的地到路由的字典；更改返回字典不改变内部状态。Route.metric 为整数，next_hop 为邻居名称或本地路由的 None。
- `advertise(neighbor: str) -> dict[str, int]`：返回针对该直连邻居的新通告字典；未知邻居抛 `ValueError`。
- `tick() -> None`：推进一轮；达到 timeout 的邻居向量过期，直连链路保留。

## 行为要求（Behavioral Requirements）

每个邻居的自身距离始终视为 0，即使通告中给出其他值；自己的目的地始终保持 `Route(0, None)`。对每个其他目的地计算所有候选值，饱和到 16；候选值为 16 的目的地不出现在路由表。修改链路成本立即影响计算。向邻居通告时，对下一跳恰为该邻居的路由发送 16，其他路由发送真实成本；本地路由发送 0。

同步轮次示例：A–B 成本 2，B–C 成本 3，timeout=2。

| 事件 | A 的 C 路由 | A 发给 B 的 C 值 |
|---|---|---:|
| 初始，未收通告 | 不存在 | 不存在 |
| B 发完整向量 `{B: 0, C: 3}`，A 收到 | `Route(5, 'B')` | 16 |
| A 第一次 tick，未刷新 | `Route(5, 'B')` | 16 |
| A 第二次 tick，向量到期 | 不存在 | 不存在 |
| B 再发完整向量，A 收到 | `Route(5, 'B')` | 16 |
| B–C 双方断链，B 下一轮向 A 发无 C 的完整向量 | 不存在 | 不存在 |

接收新向量替换整个旧向量，而不是逐项合并；过期和向量替换均不删除 A–B 直连路由。

## 边界情况（Edge Cases）

检查空向量、重复更新、向量包含本节点或邻居自身、成本 15 与 16 的截断、多个等成本邻居、删除不存在的邻居、向量输入被调用者修改、连续 tick 和过期后重新学习。非法向量的某一字段错误时不得保留部分更新。

## 调试指南（Debugging Guide）

每轮记录直连成本、收到的完整向量、年龄、候选 `(成本, 下一跳)`、最终路由及向各邻居发出的通告。先固定三节点链，再改变一条链路；若结果随节点遍历顺序变化，检查是否在收集完全部通告之前交付了消息。

## 测试（Testing）

公开测试覆盖链路、通告、非法输入、过期和毒性逆转；隐藏测试补充多节点、固定种子和失效场景。为自主测试独立计算预期路由，并包含相等成本与饱和值。设邻居数为 N、当前各邻居向量总项数为 V，可采用 O(N + V) 空间；每次路由计算遍历向量并对邻居排序时为 O(N log N + V)，tick 为 O(N)。课程评分器默认单测试墙钟预算为 8 秒，具体可用评分器参数调整；避免在每次候选比较时重复扫描整个网络。

## 常见问题（FAQ）

**为什么通告中遗漏 C 会删除旧路由？** 每次接收的是完整向量，新向量替代该邻居的旧信息；其他邻居仍可提供到 C 的候选。

**为什么到期后还能到达邻居？** 到期的是邻居通告，直连成本仍有效；断链须调用 `set_link(neighbor, None)`。

**为什么发给下一跳的距离是 16？** 毒性逆转阻止该邻居立即把这条依赖它的路径作为备选；较长环路仍需其他机制处理。
